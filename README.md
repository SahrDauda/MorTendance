# Ministry of Reconciliation Attendance System.

## What is this?
MorTendance is a simple web application that helps ministry leaders keep track of attendance, member information, and generate easy‑to‑read reports. It works on any modern browser and stores data in a secure database.

## Who can use it?
- **Leaders**: Mark attendance for each group, see who attended, and export data.
- **Members**: View their own attendance history (if you give them access).
- **Anyone**: No programming knowledge required – just a web browser.

## How to get started
1. **Open the app** – go to `http://localhost:3000` (or the URL provided by your admin).
2. **Log in** – use the email and password you were given.
3. **Dashboard** – see quick stats like total members, attendance rate, and new members.
4. **Attendance** – click the **Attendance** tab, select a group, and press **Add Attendance** to mark who is present.
5. **Members** – view, add, or edit member details (including phone number).
6. **Reports** – go to the **Reports** page to see charts and tables summarising attendance trends and member growth. You can also export the data as PDF, CSV or Excel.

## Exporting data
On the **Attendance**, **Members**, or **Reports** pages you will find **Export** buttons. Click them and choose the format you need – the file will download automatically.

## Frequently Asked Questions
- **Do I need to install anything?** No, just a web browser. The app runs on a server that your organization provides.
- **Is my data safe?** Yes. All data is stored in a PostgreSQL database behind the scenes and accessed securely.
- **Can I use it on my phone?** Absolutely – the design is responsive and works on mobile devices.
